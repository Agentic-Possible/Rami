## HTTP endpoints

- `POST /api/chat`: Server-pinned OpenRouter chat relay.
- `GET /api/gutenberg`: Same-origin Project Gutenberg catalog search and EPUB download relay.
- `GET /api/covers`: Same-origin Open Library cover search and image relay.
- `GET /api/threads`: Turnstile site key for publishing a thread.
- `POST /api/threads`: Publish a thread snapshot at an unlisted link.
- `PARAMETERS /api/threads/{id}`: undefined.
- `PUT /api/threads/{id}`: Republish a thread to its existing link.
- `DELETE /api/threads/{id}`: Remove a published thread.
- `PARAMETERS /t/{id}`: undefined.
- `GET /t/{id}`: Read-only page for a published thread.
- `GET /health`: Worker liveness, no provider or storage requests.
